# AppFunction

AppFunction is an Android application built using Kotlin and Jetpack Compose that demonstrates modern Android development practices. The application allows users to browse products, filter them based on price and location, and manage product quantities through increment and decrement functionality.

## 🚀 Features

- Product Listing
- Filter Products by Price
- Filter Products by Location
- Quantity Increment Functionality
- Quantity Decrement Functionality
- Responsive Jetpack Compose UI
- Modern Android Development Practices
- Clean and Scalable Code Structure

## 🛠️ Tech Stack

- Kotlin
- Jetpack Compose
- Android Studio
- Material Design 3
- MVVM Architecture
- State Management

## 📱 Functionalities Implemented

### Product Filtering
Users can filter products based on:
- Price
- Location

### Quantity Management
Users can:
- Increase product quantity
- Decrease product quantity
- Manage product selection efficiently
